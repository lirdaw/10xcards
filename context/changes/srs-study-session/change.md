## Notes

Sesja nauki SRS: zalogowany user uczy się wybranej talii w sesji powtórek. Do sesji wchodzą wyłącznie karty w stanie accepted; gotowy algorytm SRS (FSRS via ts-fsrs, decyzja F-02) wybiera karty należne dziś; user ocenia przypomnienie na każdej karcie, a ocena przesuwa następny termin (znane odraczane dalej, trudne wcześniej); harmonogram przeżywa między sesjami — żadna karta nie ginie, nic się nie psuje. Prereqs F-01/F-02/S-02 (wszystkie Done). Twardy warunek odbioru: test poprawności harmonogramu na harnessie z F-03. PRD: US-02, FR-011, FR-012. (source: C10X-6)
